# 🚀 GitHub Portfolio Analyzer

## 🚨 The Problem Statement
When recruiters, hiring managers, and CTOs look at a standard GitHub profile, it is incredibly difficult to measure a developer's true engineering depth. A default GitHub page shows a sea of repositories and a grid of green contribution squares, but it completely fails to highlight:

* **True Tech Stack:** Which languages and tools the developer actually uses (separating original work from cloned forks).
* **Engineering Discipline:** Whether the developer uses professional practices like Conventional Commits, automated testing, or CI/CD pipelines.
* **Architectural Gaps:** The missing pieces in a developer's portfolio that prevent them from being seen as "Senior" or "Lead" material.
* **Live Impact:** Quick, accessible links to live deployments so recruiters can actually *see* the software without having to clone and run the code.

Because manually digging through source code takes too much time, recruiters often skip it—meaning talented developers miss out on opportunities just because their GitHub doesn't easily translate into a strong, readable "resume."

---

## 💡 The Solution
The **GitHub Portfolio Analyzer** is a high-fidelity intelligence engine that transforms any standard GitHub profile into a deep, recruiter-ready technical audit. It bridges the gap between raw code and hiring signals by providing:

1. **Algorithmic Signal Scoring:** It fetches real-time data via the GitHub API to calculate a quantitative score (out of 100) based on repository health, commit discipline, and documentation fidelity, categorizing the developer into tiers (e.g., *World-Class Engineer*, *Lead-Grade Potential*).
2. **AI-Powered Recruiter Verdict:** Integrated with Google's Gemini AI, the system acts as a virtual CTO. It scans the portfolio's architecture and generates a brutal, professional assessment of the developer's strengths, complete with tailored interview questions.
3. **Intelligent Architectural Gaps:** The engine analyzes the tech stack of original repositories and identifies professional missing links (e.g., pointing out a lack of Docker in backend projects, or missing automated testing in React apps).
4. **Interactive Recruiter Chatbot:** A built-in AI assistant that allows hiring managers to ask specific, conversational questions about the developer's portfolio (e.g., "What is their strongest backend project?"), providing instant, context-aware answers.
5. **Project Revival Engine:** Automatically identifies abandoned or "dead" repositories and uses AI to generate step-by-step technical roadmaps to resuscitate them and bring them up to modern production standards.
6. **Codebase X-Ray & Shadow Profiling:** Visually maps out repository file trees to demonstrate architectural complexity without requiring code clones, and assigns a psychological "Shadow Persona" (e.g., *Elite Architect*, *Feature Factory*) based on historical coding habits.
7. **Data Visualization & Analytics:** It features rich, interactive dashboards, including exact 30-day daily contribution charts, impact heatmaps, and a curated "Live Project Showcase" that automatically extracts and displays deployed applications.

**In short:** It turns a messy repository history into a clean, actionable, and data-driven portfolio that speaks the language of tech recruiters.
